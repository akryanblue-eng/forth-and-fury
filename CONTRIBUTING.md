# Contributing to Fourth & Fury

Thanks for wanting to build a ridiculous football game. This project is in early concept / pre-production, so the most valuable contributions right now are **design pressure-testing** and **small prototype spikes** — not big feature PRs against code that doesn't exist yet.

## The One Rule

Every proposal has to answer: **which design pillar does this serve, and does it break another one?**

The five pillars are in [`docs/design-pillars.md`](docs/design-pillars.md). Each one also has a "line we won't cross." A contribution that serves no pillar, or that feeds one pillar by violating another's line, will be sent back — not because it's bad, but because it's off-mission.

## Ways to Contribute Right Now

- **Pressure-test the design.** Poke holes in the pillars. If you can describe a "cheese" strategy our Counter-Play Defense couldn't answer, that's gold — open an issue.
- **Claim a Phase 0–1 issue.** See [`docs/initial-issues.md`](docs/initial-issues.md) for the first slice of concrete work.
- **Prototype spikes.** Small, throwaway experiments that prove (or kill) an idea. Label the PR clearly as a spike.

## Workflow

1. Open or find an issue before doing significant work, so we don't duplicate effort.
2. Branch off the default branch. Keep branches focused.
3. Reference the issue and the relevant pillar(s) in your PR description.
4. Open the PR as a draft until it's ready for review.

## Tone

The game is chaotic and absurd on purpose. The systems underneath it are honest and readable on purpose. Keep both in mind — the fun rides on top of fair mechanics.
